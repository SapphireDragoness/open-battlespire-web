OpenBattlespire

An open-source engine for An Elder Scrolls Legend: Battlespire (1997). It plays the game from your own copy: choose the folder where Battlespire is installed (the GOG or Steam release).

The files are read here, in this browser tab, and kept in this browser's storage so you only choose the folder once. Nothing is uploaded anywhere.

Your saved games and settings are kept in this browser too. Clearing this site's data deletes them.
